# 📱 UPI QR Code Generator

A simple Python-based QR Code Generator that creates UPI payment QR codes for PhonePe, Paytm, and Google Pay using a UPI ID.

---

## 📌 Project Overview

This project generates payment QR codes from a user's UPI ID.

The program creates UPI payment links and converts them into QR codes that can be scanned using compatible UPI payment applications.

The project was built using Python and the `qrcode` library.

---

## ✨ Features

- 🔹 Takes a UPI ID as input
- 🔹 Generates a UPI payment QR code
- 🔹 Creates QR codes for:
  - PhonePe
  - Paytm
  - Google Pay
- 🔹 Displays the generated QR codes
- 🔹 Simple command-line interface
- 🔹 Lightweight and beginner-friendly Python project

---

## 🛠️ Technologies Used

- Python 🐍
- `qrcode` Python library
